# Maison Aube

Boutique e-commerce de démonstration construite avec React et Vite.

## Démarrer

Installez Node.js, ouvrez un terminal dans ce dossier, puis lancez :

```bash
npm install
npm run dev
```

Vite affichera l’adresse locale du site. Pour créer la version de production :

```bash
npm run build
```

Les images et les polices sont chargées depuis Unsplash et Google Fonts. Le panier et les favoris sont enregistrés dans le navigateur. Le parcours de commande est une maquette et ouvre un e-mail de commande.
